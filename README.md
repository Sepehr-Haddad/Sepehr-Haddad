## 🚀 چی می‌سازم

**[تولیدی‌محتوا](https://www.tolidimohtava.ir)** — یک پلتفرم آنلاین که تولید محتوای حرفه‌ای رو برای کسب‌وکارهای کوچیک ایرانی در دسترس می‌کنه: ریلز، تیزر، ویدیو محصول، پست اینستاگرام، طراحی لوگو و موشن‌گرافیک، همه از سفارش تا تحویل داخل یک پنل.

- 🧠 **استودیو سناریو** — تحلیل خودکار پیج اینستاگرام و تولید روزانه‌ی سناریوهای ریل/استوری آماده‌ی ضبط
- 💳 **سفارش تا تحویل، آنلاین** — انتخاب کار → پرداخت → تیم تخصصی (سناریونویس، تدوینگر، صداپیشه، کاورساز) → تحویل و بازبینی در پنل
- 🧪 **ادیتورهای آزمون‌داده** — هر ادیتور قبل از ورود به تیم آزمون عملی می‌ده و بر اساس امتیاز پروژه می‌گیره
- 🏷️ **قیمت‌گذاری شفاف** — از ۷۹ هزار تومان، سه مسیر سفارش (تعرفه‌ای / بر اساس نمونه / بر اساس لینک مرجع)
- 🛠️ **خدمات برنامه‌نویسی جانبی** — ربات تلگرام و چت‌بات، امنیت و پاکسازی سایت هک‌شده، تکمیل پروژه‌ی نیمه‌کاره، اتوماسیون و اسکرپینگ، بک‌اند/API

> این ریپازیتوری فقط شامل لینک، تصویر نمونه و توضیحاته — کد پروژه به‌صورت اختصاصی و خصوصی نگه‌داری می‌شه.
